# 20-10 & Heart Animations (HTML/CSS/JS)

---

## Giới thiệu

Kho lưu trữ chứa các trang web hiệu ứng hoạt hình đơn giản được viết bằng HTML, CSS và JavaScript thuần:

1. **Hiệu ứng Hoa nở ban đêm (`2010.html`)**:
   - Hiệu ứng hoa nở rực rỡ và phát sáng lung linh trên nền trời đêm.
   - Đi kèm thông điệp chúc mừng ý nghĩa (dành cho ngày 8/3, 20/10 hoặc các dịp đặc biệt).
   - Sử dụng CSS keyframe animation chi tiết kết hợp cùng [style.css](file:///d:/nam1/html/style.css) và [main.js](file:///d:/nam1/html/main.js).

2. **Hiệu ứng Trái tim hạt đập (`heart.html`)**:
   - Hiệu ứng trái tim đập (beating heart) tạo bởi hàng trăm hạt sáng lấp lánh trên nền HTML5 Canvas.
   - Chuyển động mượt mà bằng JavaScript và thuật toán hạt particle.

---

## Cách chạy thử

Không cần cài đặt thư viện hay build phức tạp:

1. Clone hoặc tải repo này về máy.
2. Mở trực tiếp file `2010.html` hoặc `heart.html` bằng bất kỳ trình duyệt web nào (Google Chrome, Microsoft Edge, Firefox, Safari,...).
3. (Tùy chọn) Mở bằng extension **Live Server** trong VS Code để xem mượt mà nhất.
